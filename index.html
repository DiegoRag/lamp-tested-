Projeto LAMP · SENAC · FMABC

Primers LAMP conferidos e simulados do rosa ao amarelo.

Analise um conjunto de primers contra a sequência-alvo, desenhe conjuntos novos e veja como os tubos do ensaio colorimétrico devem virar de cor. Tudo roda no seu computador.

Como instalar Ver o código

Diluições do alvo viram em tempos diferentes; o controle negativo (à direita) continua rosa.

O que faz

Três etapas no site local, mais uma página que liga os primers à simulação da reação.

01 · Análise

Confere um conjunto

Localiza F3, F2, F1, B1c, B2c, B3c e os laços nas duas fitas, com até 3 erros de base. Mede distâncias, Tm, GC, ponta 3′, grampos e dímeros, e aponta cada regra quebrada.

02 · Desenho

Propõe conjuntos novos

Percorre o alvo inteiro e devolve as 5 melhores propostas, cada uma com um núcleo diferente, ordenadas pela Tm e pelo pior dímero com a ponta 3′ pareada.

03 · Tubos

Simula a reação

Converte os erros de base em eficiência prevista e simula 9 tubos (de 10⁶ a 1 cópia e os controles), com a cor do vermelho de fenol e o pH minuto a minuto.

Como o site lê um conjunto

As seis regiões e os laços de um conjunto LAMP, na ordem em que caem no alvo. As distâncias entre elas são as réguas da Análise.

Nenhuma sequência sai da sua máquina. O site é um servidor local que escuta só em 127.0.0.1 (ADR-0013, regra 3). Esta página apresenta o projeto; para analisar primers, instale e rode no seu computador. Sequências de isolados clínicos nunca entram no repositório.

Instalar e rodar

Requer Python 3.12 ou mais novo. Todas as dependências têm versão fixa.

  1. Baixe o código e instale as dependências: 
    git clone https://github.com/DiegoRag/lamp-tested-.git
cd lamp-tested-
pip install -r requirements.txt
  2. Confira que está tudo verde (354 testes): 
    ruff check .
pytest -q
  3. Suba o site e abra http://127.0.0.1:8000 no navegador: 
    # PowerShell
$env:PYTHONPATH = "src"; python -m interface

# Linux / macOS / Git Bash
PYTHONPATH=src python -m interface
  4. Ou use a linha de comando (a saída fica em saida/): 
    PYTHONPATH=src python -m primers analisar --entrada tests/dados/conjunto_ok.csv \
  --alvo tests/dados/alvo_ok.fasta --saida saida/analise
PYTHONPATH=src python -m primers desenhar --alvo tests/dados/alvo_ok.fasta --saida saida/desenho
